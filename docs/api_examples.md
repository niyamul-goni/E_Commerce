# API Examples

## Auth
- `POST /api/v1/auth/register`
- `POST /api/v1/auth/login`
- `GET /api/v1/auth/me`

## Catalog
- `GET /api/v1/products`
- `GET /api/v1/products/search?query=watch&category_id=1`
- `POST /api/v1/products`
- `GET /api/v1/categories`
- `GET /api/v1/suppliers`
